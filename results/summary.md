## 2. Tier-3 rule verification

91 adversarial cases. **HRT guardrail accuracy: 100%**, **regex baseline: 45%**.

Original suite (28 cases): HRT 100%, regex 39%. Extended suite (63 cases: IPv6 and address encodings, CIDR overlap, ordering, conflicts with deployed rules, option smuggling, Snort signatures): HRT 100%, regex 48%. Snort signatures alone (20): HRT 100%, regex 30%. HRT accepted 0 unsafe rules and rejected 0 safe ones.

The regex baseline accepted 50 unsafe rules.

Caveat: the cases were written by the same team that wrote the gate, so this shows coverage of known tricks, not an independent audit.

Limits: Attribution can still be steered among the retrieved techniques (grounding checks membership, not correctness). Payloads are a hand-written corpus, not an adaptive attacker. Poisoning is simulated by appending text to retrieved documents.
